# Skill Forge (kendini geliştiren sistem)

1. Bir görevde aynı bilgiyi/kararı ikinci kez açıklıyorsan → skill adayıdır.
2. `.claude/skills/<kebab-ad>/SKILL.md` oluştur: frontmatter (`name`, tetikleyici kelimeler içeren `description`), sonra: Ne zaman / Proje dosyaları / Kurallar / Kontrol listesi.
3. Yalnızca projede **gerçekten var olan** dosya ve araçlara atıf yap. Kullanılamayan araçlar (Figma, Blender, Rive editörü) için "insan tarafından üretilir, entegrasyon noktası şurası" yaz.
4. Bir skill yanlış yönlendirdiyse aynı oturumda düzelt; eskiyen bilgiyi sil.
5. `CLAUDE.md` içindeki skill listesine bir satır ekle.
